# 标准使用工作卡

## 原则

以现行有效的中国GB、GB/T、SL/T及地方标准为依据。标准名称、编号、版本和适用条款在引用前核实；草案、征求意见稿和失效标准不得作为最终设计依据。

## 常用路由

| 工作 | 首先核对 |
|---|---|
| 洪水影响评价 | SL/T 808—2025 |
| 水利工程等级与洪水标准 | 工程等级、防洪标准及相应专业规范 |
| 施工导流与围堰 | 施工组织、导流及围堰相关现行标准 |
| 堤防、河道整治 | 堤防、河道治理、护岸防冲相关标准 |
| 水库调洪与大坝安全 | 水库调洪、工程等级和大坝安全评价相关标准 |
| 初设、可研 | 相应报告编制规程与项目批复要求 |

## 引用方式

在报告中写“依据××标准第×章/附录，采用××方法”；不要只列标准名称。涉及多个标准时，说明分别控制什么问题以及冲突时的处理原则。
